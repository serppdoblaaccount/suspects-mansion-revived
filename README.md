# Suspects: Mansion Revived

Juego fan-made para navegador inspirado en los juegos de misterio social. Proyecto independiente de la iniciativa REVIVIENDO SUSPECTS.

## Demo 0.1

La primera versión es una demo local para un jugador:
- Interfaz adaptable a móvil y ordenador.
- Mapa 2D con cuatro habitaciones.
- Movimiento con WASD, flechas o controles táctiles.
- Tres pistas para investigar.
- Temporizador, objetivos, reunión final y pantalla de resultado.

## Jugar

Cuando GitHub Pages esté activado, el juego estará disponible en:

`https://serppdoblaaccount.github.io/suspects-mansion-revived/`

Para probarlo en local, abre `index.html` en un navegador.
